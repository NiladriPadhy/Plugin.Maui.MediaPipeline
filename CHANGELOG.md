# Changelog

## 1.0.0

- Fluent camera / gallery / file / stream / bytes pipeline for .NET MAUI on iOS and Android
- Resize, JPEG compress, EXIF strip, orientation correction
- Text and image watermarks
- Region blur and redaction
- AES-256-GCM encryption with a decrypt helper
- HTTP multipart upload plus `IMediaUploader` / `IMediaVault` hooks for SmartUpload and FileVault
- Target size (`MaxBytes`) with quality and scale fallback
- .NET MAUI support for iOS and Android (`net10.0-ios`, `net10.0-android`)
